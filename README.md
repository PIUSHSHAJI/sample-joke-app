# ⚡ Minimalist Joke Generator

A simple, interactive front-end web application that fetches hilarious random dad jokes using a public REST API. 

## 🚀 Live Demo
You can view the live running project here: [Launch App](https://github.io)

## 🛠️ Built With
* **HTML5** - Page structure and semantic elements
* **CSS3** - Custom styling, layout cards, and button interactivity
* **JavaScript (ES6+)** - Asynchronous fetch requests linking to the remote Dad Joke API

## 📝 How it Works
1. The user launches the landing page interface.
2. Clicking the **"Get a Joke"** button fires an asynchronous `fetch()` event wrapper.
3. The application communicates with the JSON API stream, parses the incoming response string, and injects the text dynamically into the interface layout.
